## 🚀 Kako pokrenuti

1. Kloniraj ili preuzmi repozitorij
2. Otvori `index.html` direktno u pregledniku
3. **Ili** hostaj na GitHub Pages:
   - Idi na Settings → Pages
   - Odaberi `main` granu kao izvor
   - Stranica će biti dostupna na: `https://filip3845-dev.github.io/mini-sirana-kolaric/`

## 📝 Prilagodbe

### Dodaj svoj telefonski broj
Otvori `index.html` i zamijeni `+38569xxxxxxx` s pravim brojem:
```html
<p><a href="tel:+38569xxxxxxx">Pozovi nas</a></p>
```

### Dodaj svoju e-mail adresu
```html
<p><a href="mailto:info@sirana-kolaric.hr">Pošalji e-mail</a></p>
```

### Prilagodi Google Mapu
Zamijeni iframe src s tom lokacijom iz Google Mape:
1. Otvori Google Mape
2. Desni klik na lokaciju → "Dijeli"
3. Klikni na "Ugradi mapu"
4. Kopiraj kod i zamijeni iframe u `index.html`

### Dodaj slike proizvoda
Dodaj `images/` mapu sa slikama i prilagodi HTML:
```html
<div class="product-card">
    <img src="images/sir.jpg" alt="Sir">
    <h3>Trajni sir</h3>
    <p>Opis...</p>
</div>
```
